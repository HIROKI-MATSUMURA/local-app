# WebAssembly テストスイート

## 概要

このテストスイートは、Python依存から WebAssembly/JavaScript 実装への移行が正しく行われていることを検証するためのものです。

## テストの実行方法

テストを実行するには、プロジェクトのルートディレクトリで以下のコマンドを実行します：

```bash
npm run test-webassembly
```

## テスト内容

テストスイートは以下の5つの主要な領域をカバーしています：

1. **WebAssembly Bridge Adapter テスト**
   - 環境チェック機能
   - 環境セットアップ機能
   - 関数登録メカニズム

2. **WebAssembly Image Analyzer テスト**
   - 色抽出機能
   - テキスト抽出機能 (OCR)
   - レイアウト分析機能
   - セクション分析機能
   - カード要素検出機能
   - 特徴要素検出機能
   - 総合分析機能

3. **アプリケーション API テスト**
   - アプリケーションが提供するAPIが正しく機能することを検証
   - 実際のアプリケーションコードを通したエンドツーエンドテスト

4. **Python 依存関係切断の検証**
   - Python ブリッジの非依存性確認
   - WebAssembly モードの有効化確認
   - 必要な依存関係がパッケージに含まれていることの確認
   - ビルド設定の正確性確認

5. **互換性・パフォーマンステスト**
   - 各機能の処理時間計測
   - メモリ使用量のチェック
   - パフォーマンスが許容範囲内であることの確認

## 問題発生時の対応

テスト実行中にエラーが発生した場合：

1. エラーメッセージを確認し、問題が発生した具体的なテストを特定
2. 関連するWebAssembly実装ファイルを確認
3. 必要に応じてmockオブジェクトやテスト環境を調整

## テスト拡張

新しいWebAssembly機能を追加した場合は、以下の手順でテストを拡張してください：

1. 適切なテスト関数に新しいテストケースを追加
2. 必要に応じてモックデータやヘルパー関数を追加
3. README.mdを更新して新しいテストについて説明

## 依存関係

このテストスイートは以下のライブラリに依存しています：

- jsdom: DOMシミュレーション用
- canvas: 画像処理操作のシミュレーション用

これらの依存関係は `devDependencies` にリストされており、`npm install` でインストールされます。
