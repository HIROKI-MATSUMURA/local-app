# AIコード生成の処理フロー

## 概要
画像から自動的にHTMLとSCSSコードを生成するアプリケーションの処理フローを記載

## 正しい処理フロー

```
画像アップロード
↓
コード生成ボタン押下
↓
画像解析実行（WebAssembly）
↓
画像解析結果をJS分析処理
↓
その結果をプロンプトに反映
↓
AIに送信（Claude/GPT）
↓
AIの生成結果が返ってくる
```

## 各段階の詳細

### 1. 画像アップロード
- PC用画像またはSP用画像をアップロード
- Base64形式に変換
- 必要に応じてリサイズ処理

### 2. コード生成ボタン押下
- ユーザーがコード生成を開始
- 画像解析とAI処理を開始

### 3. 画像解析実行（WebAssembly）
- **OpenCV.js**: 色抽出、レイアウト分析、UI要素検出
- **Tesseract.js**: OCRによるテキスト抽出
- 以下の情報を取得：
  - 主要色（K-meansクラスタリング）
  - レイアウトタイプ（グリッド、カード、リストなど）
  - UI要素（ボタン、フォーム、ナビゲーション）
  - メインセクション（ヘッダー、メイン、フッター）
  - テキスト情報（OCR）

### 4. 画像解析結果をJS分析処理
**現在未実装 - 要開発**
- 解析結果を構造化
- 色情報の整理（RGB、HEX、役割の推定）
- レイアウト情報の文章化
- UI要素の配置と種類の整理
- テキスト情報の整理

### 5. その結果をプロンプトに反映
**現在未実装 - 要開発**
- 基本プロンプトに解析結果を統合
- 色情報、レイアウト、UI要素をテキスト形式でプロンプトに追加
- より具体的で正確なコード生成指示を作成

### 6. AIに送信
- 強化されたプロンプト + 画像をAIに送信
- HTMLとSCSSコードの生成依頼

### 7. AIの生成結果処理
- 生成されたコードを受信
- HTMLとSCSSに分割
- プレビュー表示

## 技術詳細

### 画像解析技術スタック
- **OpenCV.js**: ブラウザ用OpenCVライブラリ
- **Tesseract.js**: ブラウザ用OCRライブラリ
- **WebAssembly**: 高性能画像処理実行環境

### ファイル構成
- `src/electron/components/AICodeGenerator.jsx`: メインコンポーネント
- `src/electron/utils/imageAnalyzer.js`: 画像解析ブリッジ
- `src/electron/utils/webassembly-image-analyzer.js`: 実際の解析実装
- `src/electron/utils/webassembly-bridge-adapter.js`: アダプター

## 備考
- 現在の画像解析結果はコンソールログにのみ出力される
- モックデータは一切使用せず、実際の解析結果のみを利用
- エラー時はダミーデータに頼らず、適切なエラーハンドリングを実装
